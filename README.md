## 🚀 Featured Engineering Projects

### 01. [CloudPulse — Self-Healing Cloud-Native Microservices Platform](https://github.com/shiva-kumar-1319/CloudPulse)
`CLOUD-NATIVE` · `DISTRIBUTED SYSTEMS` · `MLOPS` · `KUBERNETES`

> A microservices platform (auth, order, inventory services) where an ML anomaly detector watches Prometheus telemetry in real time. When latency spikes or error rates cross a threshold, a Remediation Controller validates safety guardrails (confidence threshold, cooldown window, rate limits) and calls the Kubernetes API to recycle or scale pods — closing the loop from detection to recovery automatically.

```
Microservices (FastAPI)
       │
       ▼
RabbitMQ (Async Event Broker)
       │
       ▼
Prometheus Telemetry Ingestion (Scraping pod CPU, memory & error rates)
       │
       ▼
ML Anomaly Detection (Isolation Forest streaming inference)
       │
       ▼
Remediation Controller (Cooldown window, confidence score & rate limits)
       │
       ▼
Kubernetes API (Pod recycling & dynamic horizontal scaling)
       │
       ▼
Automated Recovery (Zero-Downtime Autonomous Remediation)
```

- **Key Highlights**:
  - Live Isolation Forest unsupervised anomaly detection on multidimensional metrics stream.
  - Automated Kubernetes pod recycling and horizontal pod autoscaling (HPA).
  - Microservices decoupling via RabbitMQ message broker.
  - Chaos engineering validation under injected latency, memory exhaustion, and cascading 500 errors.
- **Tech Stack**: `FastAPI` · `PostgreSQL` · `RabbitMQ` · `Docker` · `Kubernetes` · `Terraform` · `Prometheus` · `Grafana` · `Isolation Forest`

  - Production deployment and health telemetry running live on Render.
- **Tech Stack**: `Flask` · `PostgreSQL` · `Gemini 2.0 Flash` · `JWT` · `REST APIs` · `Render`

### 03. [IDQS — Intelligent Document Query System](https://github.com/shiva-kumar-1319/Chat-with-Multiple-PDF-s)
`NLP` · `INFORMATION RETRIEVAL` · `RAG` · `LANGCHAIN`

> A document QA system built on LangChain's `ConversationalRetrievalChain`, using a FAISS vectorstore over `flan-t5-base` embeddings. Chunks documents with a `CharacterTextSplitter` (size 1000, overlap 200) and supports querying across up to 5 PDFs simultaneously — validated across 20–30 test queries.

- **Key Highlights**:
  - Multi-document conversational retrieval with chat history context preservation.
  - Simultaneous querying across up to 5 dense technical PDFs without context degradation.
  - Tuned chunking parameter strategy (size: 1000, overlap: 200) for high semantic relevance.
  - Local vector indexing with FAISS and Hugging Face transformer embeddings.
- **Tech Stack**: `LangChain` · `FAISS` · `flan-t5-base` · `PyTorch` · `Python`

### 04. Animal Keypoint Estimation Suite
`COMPUTER VISION` · `DEEP LEARNING` · `ONNX`

> Browser-based real-time 2D skeletal keypoint detection for quadruped animals (cats, dogs, cows, horses, sheep), using a YOLOv8-nano + RTMPose-Medium ONNX pipeline with AP-10K → Animal-Pose 20-joint schema mapping.

- **Key Highlights**:
  - Real-time client-side neural inference running inside the browser without GPU server costs.
  - Multi-species quadruped topology mapping across 5 distinct animal classes.
  - Unified 20-joint skeletal graph translating AP-10K to Animal-Pose standard.
  - Two-stage detector-pose architecture (YOLOv8-nano + RTMPose-Medium).
- **Tech Stack**: `YOLOv8` · `RTMPose` · `ONNX Runtime` · `OpenCV` · `PyTorch`
